# Yanix web

Next.js (App Router, TypeScript strict, Tailwind) frontend for Yanix.

```sh
pnpm install
pnpm dev            # http://localhost:3000, expects the API on :8000
pnpm lint
pnpm typecheck
pnpm test           # Vitest unit tests
pnpm build
```

Configuration (environment variables, read on the server at request time):

| Variable | Default | Meaning |
|---|---|---|
| `YANIX_API_URL` | `http://localhost:8000` | Base URL the server uses to call the API |

## Code layout

| Path | What lives there |
|---|---|
| `app/page.tsx` | Landing page; calls the API health endpoint |
| `app/desktop/page.tsx` | The desktop lab ([ADR 0002](../docs/adr/0002-build-a-desktop-lab-ahead-of-the-roadmap.md)) |
| `lib/api/` | API calls |
| `lib/xray/` | Desktop lab model, with tests and no React: the node map (`nodes.ts`), the simulated computer (`apps.ts`), packets and data structures (`packets.ts`, `structs.ts`), one module per scenario (`scenarios/`) and the playback reducer (`engine.ts`) |
| `components/lab/` | Machine view (SVG and Motion), narration, data panel, playback bar |
| `components/desktop/` | The simulated desktop: power screens, windows, taskbar, browser, terminal, text editor, media player |

`AGENTS.md` and `CLAUDE.md` in this folder are generated by Next.js and point
AI assistants at the docs bundled in `node_modules/next/dist/docs/`.
